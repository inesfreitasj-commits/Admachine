TESTING PLAYBOOK
================================================================
Budget      : 10-15 € per creative per day, each in its own ad set so the
              algorithm can't starve a variation before it gets a read.
Duration    : 3 days minimum. Judge on 1 000+ impressions per creative, never
              earlier — this audience skews 45-65 and converts slowly.
Kill        : Stop a creative at 30 € spend with 0 purchases, or CTR under
              0.8 %, or CPC 2x your account average.
Scale       : A winner is 2x account-average CTR AND at least 2 purchases.
              Move it to its own campaign, then iterate on the variation axis
              that won (see per-concept axis below) — that axis is your next
              test, not a fresh concept.
Pairing     : Always read var_01 vs var_02 against each other first. Only one
              thing changes between them, so the winner tells you WHY it won.

KNOWN ISSUES — READ BEFORE RUNNING
================================================================
1. COMPLIANCE, concept_03. The quote is verbatim from your own sales page, but
   the woman pictured is an AI-generated model, not Dr Monique Delorme. Showing
   a synthetic face beside a named real professional's quote is a real exposure.
   Either swap in a licensed photo of the actual doctor, or drop the name and
   run it as an anonymous "gynécologue" endorsement.

2. LABEL MOTIF. The generator renders the label's botanical mark as a lotus/
   petal rather than your actual stylised motif. Arguably safer for ad-platform
   review, but it is not your real packaging. Check before scaling spend.

3. SMALL-BOTTLE SHOTS. Where the bottle sits small in frame (concept_01_var_02),
   the label micro-copy is still fuzzy. Invisible at feed size, wrong if anyone
   zooms.

4. AI MODELS. Every person shown is generated. Standard practice, but Meta
   disclosure rules on synthetic media in ads are worth a check for your market.

5. _v1_blurred_label/ holds the first pass, before the label-text fix. Kept for
   comparison only — do not run those.
