# Concept 02 — Features & Benefits (matches their product+bullets winner)

## Scene
A clean premium product advertisement. The ÉveilSens bottle stands upright on a soft blush-pink surface, three-quarter view, label fully readable, gentle studio lighting with a soft shadow, a few delicate cherry-blossom petals scattered nearby. Generous negative space on the left for text.

## Text overlays
Bold dark-magenta text stacked on the left, each line preceded by a small magenta check mark:
✓ 2 GOUTTES SEULEMENT
✓ EFFET EN 90 SECONDES
✓ SENSATIONS DÉMULTIPLIÉES
Small line underneath in grey: 100 % NATURELLE · SANS HORMONES

## Headline
2 gouttes. 90 secondes. Sensations démultipliées.

## Caption
Formule 100 % naturelle, sans hormones, sans parabènes. Compatible préservatifs. Livraison discrète en 3 à 7 jours.

## Variation axis: background
- var_01: Clean blush-pink studio seamless background.
- var_02: Same layout and text, but set on a real wooden bedside table at night with a warm lamp glowing behind.
